# ระบบพยากรณ์อากาศและภัยธรรมชาติ

เว็บแอปพลิเคชันสำหรับพยากรณ์อากาศ ทำนายฝน วิเคราะห์ความเสี่ยงน้ำท่วม ติดตามแผ่นดินไหว และน้ำขึ้นน้ำลง
เป็นเว็บแบบ static (HTML/CSS/JavaScript) ใช้ข้อมูลจริงจาก API สาธารณะ **ไม่ต้องใช้ API key**

## วิธีรัน

```bash
python -m http.server 8080
```

แล้วเปิด http://localhost:8080 (หรือดับเบิลคลิก `index.html` ได้เลย)

## ฟีเจอร์

| โมดูล | รายละเอียด | แหล่งข้อมูล |
|---|---|---|
| 🌤️ พยากรณ์อากาศ | สภาพอากาศปัจจุบัน, กราฟ 24 ชม., พยากรณ์ 16 วัน, เลือกตำแหน่งบนแผนที่ | Open-Meteo Forecast |
| 🌧️ ทำนายฝน | ดัชนีโอกาสฝน (0–100) จากโอกาสฝนของแบบจำลอง + ความชื้น + เมฆ + CAPE + แนวโน้มความกดอากาศ, ฝนสะสม 24/72 ชม., จำแนกระดับฝนตามเกณฑ์กรมอุตุฯ, เตือนพายุฝนฟ้าคะนอง | Open-Meteo Forecast |
| 🌊 วิเคราะห์น้ำท่วม | ระดับความเสี่ยง 5 ระดับ จากอัตราการไหลของแม่น้ำ (เทียบสถิติย้อนหลัง 3 ปี), ฝนคาดการณ์ 3 วัน, ฝนสะสมย้อนหลัง 7 วัน และความสูงของพื้นที่ พร้อมคำแนะนำ | Open-Meteo Flood (GloFAS) |
| 💧 ข้อมูลน้ำ/เขื่อน | ปริมาณน้ำ 35 เขื่อนใหญ่ (% รนก., น้ำใช้การ, ไหลเข้า/ระบาย), ระดับน้ำ ~800 สถานี (% ความจุลำน้ำ, ล้นตลิ่ง, แนวโน้ม), ฝน 24 ชม. ~4,400 สถานี, สถานการณ์น้ำรอบตำแหน่ง, แผนที่หลายชั้นข้อมูล | [ThaiWater](https://www.thaiwater.net) `thailand_main`, `rain_24h` |
| 🌐 แผ่นดินไหว | แผนที่และตาราง กรองตามช่วงเวลา/ขนาด/รัศมี, ระยะห่างจากตำแหน่ง, ประเมินการรับรู้แรงสั่น, แจ้งเตือนสึนามิ | USGS |
| 🌙 น้ำขึ้นน้ำลง | กราฟระดับน้ำทะเล 7 วัน, เวลาน้ำขึ้นสูงสุด/น้ำลงต่ำสุด, แนวโน้มปัจจุบัน, จุดชายฝั่งไทย 9 จุด | Open-Meteo Marine |

### การใช้ข้อมูล ThaiWater ช่วยทำนาย

- **ทำนายฝน**: เปรียบเทียบฝนตรวจวัดจริงจากสถานีใกล้เคียง (รัศมี 20–40 กม.) กับค่าแบบจำลอง และเกณฑ์เตือนภัยของแต่ละโซน
- **วิเคราะห์น้ำท่วม**: เพิ่ม 3 ปัจจัย — ฝนตรวจวัดจริงเทียบเกณฑ์โซน, ระดับน้ำจริงในลำน้ำ (รัศมี 30 กม.), เขื่อนใกล้เคียงที่น้ำมาก (รัศมี 100 กม.)
- ค่าฝนสูงผิดปกติที่สถานีข้างเคียงไม่ยืนยัน จะถูกลดน้ำหนักและแจ้งให้ตรวจสอบ
- ข้อมูล ThaiWater เป็นข้อมูลระดับประเทศ แคชไว้ 15 นาที (กดรีเฟรชเพื่อโหลดใหม่)

## โครงสร้างไฟล์

```
index.html      หน้าเว็บหลัก (5 แท็บ)
css/style.css   สไตล์ (รองรับโหมดมืด/มือถือ)
js/app.js       ตรรกะทั้งหมด: โหลดข้อมูล วิเคราะห์ และแสดงผล
```

> ผลการพยากรณ์และวิเคราะห์เป็นข้อมูลประกอบการตัดสินใจเท่านั้น โปรดติดตามประกาศทางการจากกรมอุตุนิยมวิทยาและ ปภ.
