# ระบบพยากรณ์อากาศและภัยธรรมชาติ

เว็บแอปพลิเคชันสำหรับพยากรณ์อากาศ ทำนายฝน วิเคราะห์ความเสี่ยงน้ำท่วม ติดตามแผ่นดินไหว และน้ำขึ้นน้ำลง
เป็นเว็บแบบ static (HTML/CSS/JavaScript) ใช้ข้อมูลจริงจาก API สาธารณะ **ไม่ต้องใช้ API key**

## วิธีรัน

```bash
python -m http.server 8080
```

แล้วเปิด http://localhost:8080 (หรือดับเบิลคลิก `index.html` ได้เลย)

### การใช้ข้อมูล ThaiWater ช่วยทำนาย

- **ทำนายฝน**: เปรียบเทียบฝนตรวจวัดจริงจากสถานีใกล้เคียง (รัศมี 20–40 กม.) กับค่าแบบจำลอง และเกณฑ์เตือนภัยของแต่ละโซน
- **วิเคราะห์น้ำท่วม**: เพิ่ม 3 ปัจจัย — ฝนตรวจวัดจริงเทียบเกณฑ์โซน, ระดับน้ำจริงในลำน้ำ (รัศมี 30 กม.), เขื่อนใกล้เคียงที่น้ำมาก (รัศมี 100 กม.)
- ค่าฝนสูงผิดปกติที่สถานีข้างเคียงไม่ยืนยัน จะถูกลดน้ำหนักและแจ้งให้ตรวจสอบ
- ข้อมูล ThaiWater เป็นข้อมูลระดับประเทศ แคชไว้ 15 นาที (กดรีเฟรชเพื่อโหลดใหม่)

### แบบจำลองทำนาย PM2.5

1. ดึงค่า PM2.5 ตรวจวัดจริงรายชั่วโมงย้อนหลัง 14 วันของสถานีที่เลือก (Air4Thai)
2. ตัวแปรต้น 11 ตัว: PM2.5/CO/NO₂/AOD จาก CAMS, ความสูงชั้นผสมอากาศ, ลม, ความชื้น, ฝนสะสม 6 ชม., อุณหภูมิ, ช่วงเวลาของวัน
3. Ridge regression บน log(PM2.5) (ตัวแปรปรับมาตรฐาน, λ = 3)
4. ทดสอบกับ 48 ชม. ล่าสุดที่แบบจำลองไม่เคยเห็น แล้วเลือกวิธีที่แม่นที่สุดของสถานีนั้น: แบบจำลองสถิติ / CAMS / ค่าเฉลี่ยทั้งสอง
5. ช่วงความเชื่อมั่น ~80% จากความคลาดเคลื่อนในช่วงทดสอบ

ทดสอบกับ 8 สถานีสุ่ม (ทำนายล่วงหน้า 72 ชม.): MAE 3.8 µg/m³ เทียบกับ CAMS โดยตรง 5.0 µg/m³

> WAQI token อยู่ใน `js/app.js` (`WAQI_TOKEN`) — ขอ token ของตัวเองได้ที่ https://aqicn.org/data-platform/token/

## โครงสร้างไฟล์

```
index.html      หน้าเว็บหลัก (5 แท็บ)
css/style.css   สไตล์ (รองรับโหมดมืด/มือถือ)
js/app.js       ตรรกะทั้งหมด: โหลดข้อมูล วิเคราะห์ และแสดงผล
```

> ผลการพยากรณ์และวิเคราะห์เป็นข้อมูลประกอบการตัดสินใจเท่านั้น โปรดติดตามประกาศทางการจากกรมอุตุนิยมวิทยาและ ปภ.
